# Library Management AI

An intelligent library management system developed to manage books, users, loans, and reviews, with AI-powered recommendation features and analytical insights.

## 🚀 Features

* Book registration and management
* User registration
* Loan control
* Return management
* Review and comment system
* AI-based book recommendations
* AI-generated review suggestions
* Analytical reports and statistics

## 🛠 Technologies Used

* Python
* PostgreSQL
* psycopg2
* matplotlib

## 🧠 Artificial Intelligence Features

* Book recommendation based on user interaction
* Automated review suggestion
* Reading pattern support
